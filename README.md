# Indiana Choice Scholarship Program Annual Report

  Full-stack web application replicating the Indiana Choice Scholarship Program Annual Report (2024-2025).

  ## Stack
  - **Frontend**: React + Vite + Tailwind CSS + shadcn/ui
  - **Backend**: Express 5 + PostgreSQL + Drizzle ORM
  - **Auth**: Replit Auth (OIDC/PKCE)

  ## Features
  - Public report with all sections, tables, and stats from the 2024-2025 annual report
  - Admin portal for team members to update content live
  - PDF download link to original report
